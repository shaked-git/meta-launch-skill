# meta-launch (lite)

סקיל ל-Claude Code שמעלה קמפיינים למטא (פייסבוק ואינסטגרם) מתוך בריף בעברית, דרך ה-Marketing API הרשמי.

כותבים ל-Claude מה רוצים: תקציב, קהל, באנרים, טקסט ולינק. הוא בונה את הקמפיין, בודק אותו מול מטא,
מראה תצוגה מקדימה של המודעות, ויוצר רק אחרי שאישרתם. **הכל נוצר כבוי (PAUSED)**, ואתם מדליקים
ב-Ads Manager.

## מה יש בגרסה הזו
- קמפיין עם ad set אחד או יותר: CBO או ABO, תקציב יומי או כולל, תקרת הוצאה.
- מודעות תמונה, וידאו וקרוסלה. אופציונלית טופס לידים של מטא.
- קהל: מדינות או רדיוס סביב נקודה, גילאים, מגדר, קהלים מותאמים, Advantage+ או ידני.
- שדות המפרסם המאומת לישראל, אוטומטית.
- כל שיפורי ה-AI של מטא על הקריאייטיב כבויים: המודעה רצה כמו שהיא.
- `status` לקריאת מצב, ו-`pause` לעצירה.

## בטיחות מובנית
- רק חשבונות שהגדרתם ב-`accounts.json`.
- תקרה יומית לכל חשבון; מעליה צריך אישור מפורש.
- אישור לפי hash: שינוי בקמפיין אחרי האישור דורש אישור חדש.
- אין הפעלה ואין מחיקה בקוד בכלל.
- כל כתיבה למטא נרשמת ב-`audit/audit.jsonl` (בלי הטוקן).

## מה אין
עריכה של קמפיינים חיים, בניית טפסים וקהלים, קריאייטיב דינמי ודוחות. את אלה עושים ב-Ads Manager.

## התקנה
כל ההקמה, כולל האפליקציה במטא, משתמש המערכת והטוקן, ב-[SETUP.md](SETUP.md). אחרי ההקמה:
[SKILL.md](SKILL.md) הוא מה ש-Claude קורא.

## חשוב לדעת
זה לא כלי רשמי של מטא. הוא פועל בשם החשבון שלכם ובכסף שלכם: עברו על כל קמפיין לפני שאתם מדליקים.
